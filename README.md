## Flagship project

### [MiniLang Compiler Studio](https://github.com/muntazirmehdibscsf24-beep/MiniLang-Compiler-Workbench)

**An interactive compiler and execution environment for a small teaching language.**

<a href="https://github.com/muntazirmehdibscsf24-beep/MiniLang-Compiler-Workbench">
  <img src="https://raw.githubusercontent.com/muntazirmehdibscsf24-beep/MiniLang-Compiler-Workbench/main/docs/MiniLang_Guide_Workspace.png" width="940" alt="MiniLang Compiler Studio in Zen Sage, showing the split source editor, compiler pipeline, and output console" />
</a>

Write MiniLang in the editor, then follow the same program from source text to output. I led the team that built the Studio to help beginners see how a compiler makes decisions.

- **Compiler pipeline** · Follow tokenization, predictive LL(1) parsing, semantic checks, and three-address code generation.
- **Interactive views** · Step through character recognition and parser decisions. Explore the parse tree, abstract syntax tree, symbol table, and control flow.
- **Execution engine** · Run generated instructions, read printed output, and trace runtime errors back to the source. Execution limits stop runaway loops.
- **Learning guide** · Work through a program by hand, compare each step with the Studio, and use the complete grammar and parsing table as a reference.

**Stack** · React · TypeScript · Monaco · React Flow · Python · FastAPI

[Explore the source](https://github.com/muntazirmehdibscsf24-beep/MiniLang-Compiler-Workbench) · [Read the beginner’s PDF guide](https://github.com/muntazirmehdibscsf24-beep/MiniLang-Compiler-Workbench/blob/main/docs/MiniLang_Complete_Beginners_Guide.pdf)
